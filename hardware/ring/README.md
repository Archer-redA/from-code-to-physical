## 打印参数（推荐值，Bambu Lab A1 mini）

| 参数 | 取值 | 原因 |
|---|---|---|
| 喷头 | 0.4 mm | A1 mini 标配 |
| 层高 | **0.12 mm** | 文字只有 0.6mm 凸起，层高太粗会看不出层次 |
| 摆放 | **平放**（戒指轴向竖直） | 关键：这样文字全是垂直棱柱，Z 方向没有悬垂面 |
| 支撑 | **关闭** | 平放后不需要；开了反而会粘在字上 |
| 墙数 | 4 | 壁厚 2.5mm，4 圈墙就基本填满了 |
| 填充 | 15% | 实际几乎全由墙填满，填充率影响很小 |
| 底座(Brim) | 3 mm（可选） | 首层是个 23mm 的圆环，附着力够，加个 Brim 更保险 |

> ⚠️ **不要立着放。** 立放时环的下半圈整体是大角度悬垂，必然塌边。
> 平放是这个小件唯一合理的摆法。

## 为什么字必须用粗体

这是 FDM 打印能不能看清文字的硬约束：

- A1 mini 喷头 0.4mm，单条挤出线宽约 0.42mm
- 实测 Arial Bold 在字高 5.5mm 时，竖笔画约 **1.07mm** ≈ 2.5 条挤出线 → 能连住
- 同样的字高换成常规字重，笔画只剩约 0.65mm ≈ 1.5 条线 → 打印时容易断线、糊成一团

所以 `FONT` 参数一定要带 `:style=Bold`。

## 怎么改

所有尺寸都在 `ring.scad` 顶部，改一个数重新出图即可，不需要重画：

```openscad
INNER_D = 18;        // 内径
WALL    = 2.5;       // 壁厚
BAND    = 8;         // 带宽
TEXT    = "ARCHER";  // 刻什么字
CAP     = 5.5;       // 字高
EMBOSS  = 0.6;       // 凸起高度
```

**改完记得核对弧长**：字太长会绕环超过一圈，字与字会自己压在一起。
出图时 OpenSCAD 会打印一行 `TEXT_SPAN_DEG`，**这个值不要超过 330°**，留出空隙。

## 怎么重新生成

```bash
# 生成 STL（二进制）
openscad --enable=textmetrics --export-format binstl \
         -o ring.stl ring.scad

# 生成预览图
openscad --enable=textmetrics --render --imgsize=1400,1000 \
         --projection=p --autocenter --viewall \
         --camera=0,0,0,60,0,25,60 -o preview-iso.png ring.scad
```

> ⚠️ **`--enable=textmetrics` 不能省。**
> `textmetrics()` 在 OpenSCAD 里是实验性内置函数，默认关闭。
> 图形界面里打开方式：**编辑 → 首选项 → 功能(Features) → 勾选 textmetrics**。
> 没有它的话，脚本会自动回退到文件内烘焙好的字宽表，仍然能出图，
> 但遇到表里没有的字符会按估算宽度排，字距会不准。

## 校验

打印前用仓库自带的工具验过水密性：

```bash
node ../tools/stl-check.js ring.stl
```

结果：

```
triangles    : 9720
open edges   : 0
non-manifold : 0
degenerate   : 0
CONCLUSION   : 通过 —— 水密流形，可以打印
```

**为什么要做这一步**：切片软件对非水密网格的处理方式不一致，可能出现
「有的地方凭空多一层墙」或者直接报错。先在源头验掉，比在切片软件里
看到莫名其妙的警告再回头查省事得多。

**事后验证**：这个模型确实一次打印成功，没有出现网格相关的报错，说明校验是有效的。

## 已知取舍

建模时明确知道、但选择接受的地方，记下来免得以后忘了：

1. **每个字母是一块切平面上的平板，不是真正贴着圆柱弯曲的。**
   代价是字母两端的凸起比中间多约 0.28mm（0.6mm → 0.88mm），
   看上去字的两端略高一点点。
   要做成完全等高的弯曲文字，得把每个字母切成上百个薄片再绕圆周旋转，
   会引入新的接缝问题，而且网格量大一个数量级。
   对这个尺寸的装饰件，0.28mm 的差异在 0.4mm 喷头下基本看不出来，选了简单可靠的方案。

2. **内圈边缘没有倒角。** 外圈上下棱有 0.4mm 倒角，内圈是直角。
   反正是戴着玩的装饰件，内圈不做处理不影响打印。

3. **不支持中文。** 中文笔画密，5.5mm 字高下笔画只有 0.3mm 左右，
   FDM 打印必然糊成一团，要刻中文得换光固化，或者把戒指做大好几倍。
